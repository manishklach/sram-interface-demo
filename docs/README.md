# Documentation & Microsite

This directory contains the documentation and the GitHub Pages microsite for the **SRAM Interface Demo**.

## Files
- `index.html`: The main microsite landing page.
- `styles.css`: Modern dark theme for the microsite.
- `architecture.svg`: High-level system architecture diagram.
- `demo-flow.svg`: Step-by-step API interaction diagram.
- `*.md`: Detailed documentation for architecture, use cases, and future directions.

## GitHub Pages
To enable the microsite:
1. Go to **Settings** > **Pages**.
2. Set **Source** to "Deploy from a branch".
3. Select **Branch: master** (or main) and **Folder: /docs**.
4. Click **Save**.

The site will be available at: `https://manishklach.github.io/sram-interface-demo/`
